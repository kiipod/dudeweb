# Шаг 1 — Анализ Landing V2 в Pen

## Цель

Полностью изучить новые страницы Landing V2 через Pen MCP
и подготовить карту реализации.

На этом шаге production-код не изменять.

## Подключение

- [x] Проверить доступность Pen MCP.
- [x] Получить список доступных страниц.
- [x] Найти страницы, относящиеся к Landing V2.
- [x] Убедиться, что используются именно новые макеты V2.
- [x] Определить актуальные варианты desktop/tablet/mobile.

Если существует несколько вариантов V2 и нельзя определить
актуальный, зафиксировать неоднозначность и остановиться.

## Результаты проверки — 2026-11-05

Живым Pen MCP изучены восемь актуальных адаптивов Landing V2
(360/390/430/768/1024/1440/1920/2560) и current Motion states board.
Эталон однозначно указан в Pen: `KwQuD`, Light · 2560.

Результат: [design-inventory.md](../../../docs/landing-v2/design-inventory.md).
Все девять разделов результата заполнены; source IDs, точные тексты,
responsive values, assets и ограничения интерактивности зафиксированы.
Отметки проверки наличия dropdown/forms/breakpoints означают завершённое
исследование: отсутствующие элементы и незаданные значения отмечены в отчёте,
не придуманы. Open Questions V2-Q01–V2-Q12 относятся к последующей реализации
и локальным расхождениям источника; неоднозначности выбора master нет.

Проверены деревья 9 frames (2845 nodes), снимки всех восьми адаптивов
и ключевых состояний. Неподключённые canvas events не выданы за работающие
browser interactions. Git diff ограничен документацией и планом;
production-код, маршрут `/` и текущая главная не менялись.
Runtime tests/build не запускались для документационного изменения.
Шаг 02 и дальнейшие этапы не выполнялись.
