# Шаг 1 — Анализ Landing V2 в Pen

## Цель

Полностью изучить новые страницы Landing V2 через Pen MCP
и подготовить карту реализации.

На этом шаге production-код не изменять.

## Подключение

- [ ] Проверить доступность Pen MCP.
- [ ] Получить список доступных страниц.
- [ ] Найти страницы, относящиеся к Landing V2.
- [ ] Убедиться, что используются именно новые макеты V2.
- [ ] Определить актуальные варианты desktop/tablet/mobile.

Если существует несколько вариантов V2 и нельзя определить
актуальный, зафиксировать неоднозначность и остановиться.

## Структура

Для каждой страницы:

- [ ] Прочитать дерево элементов.
- [ ] Определить все секции.
- [ ] Определить порядок секций.
- [ ] Найти повторно используемые компоненты.
- [ ] Найти изображения и иконки.
- [ ] Изучить тексты.
- [ ] Изучить интерактивные элементы.

## Design Tokens

Получить из Pen:

- [ ] Colors.
- [ ] Typography.
- [ ] Font weights.
- [ ] Font sizes.
- [ ] Line heights.
- [ ] Spacing.
- [ ] Container widths.
- [ ] Grid.
- [ ] Border radius.
- [ ] Shadows.
- [ ] Breakpoints, если определены.

## Интерактивность

Проверить наличие:

- [ ] Hover states.
- [ ] Active states.
- [ ] Dropdown menus.
- [ ] Mobile navigation.
- [ ] Scroll animations.
- [ ] Transitions.
- [ ] Interactive cards.
- [ ] CTA buttons.
- [ ] Forms, если предусмотрены.

Не придумывать поведение, отсутствующее в макете.

Если интерактивность визуально обозначена, но её поведение
не определено, зафиксировать вопрос в документации.

## News

Отдельно изучить блок новостей:

- [ ] Количество карточек.
- [ ] Структуру карточки.
- [ ] Заголовки.
- [ ] Изображения.
- [ ] Даты, если есть.
- [ ] Описания.
- [ ] Кнопки и ссылки.
- [ ] Mobile layout.

## Проверка

- [ ] Все страницы V2 изучены.
- [ ] Все секции перечислены.
- [ ] Тексты зафиксированы.
- [ ] Адаптивные состояния изучены.
- [ ] Интерактивность описана.
- [ ] News block изучен.
- [ ] design-inventory.md создан.
- [ ] Production-код не изменён.
