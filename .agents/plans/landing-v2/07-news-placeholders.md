# Шаг 7 — News Placeholders

## Цель

Реализовать блок новостей Landing V2 как статический
презентационный компонент.

Функционал новостей не планируется.

## Источник

Использовать макет Landing V2 в Pen.

## Данные

- [ ] Определить количество карточек.
- [ ] Перенести заголовки.
- [ ] Перенести описания.
- [ ] Перенести даты, если предусмотрены.
- [ ] Перенести изображения.
- [ ] Перенести порядок карточек.

Данные хранить локально.

Допустимые варианты:

- локальный массив в компоненте;
- отдельный статический data-файл.

Не создавать backend API.

## Component

- [ ] Создать NewsSection, если это соответствует архитектуре.
- [ ] Реализовать NewsCard, если компонент переиспользуется.
- [ ] Сохранить структуру Pen.
- [ ] Реализовать responsive layout.
- [ ] Реализовать предусмотренный slider, если он есть в макете.

## Links

Не создавать несуществующие страницы новостей.

Если макет содержит:

- "Читать далее";
- "Все новости";
- ссылки на отдельные публикации;

проверить, существует ли реальное назначение ссылки.

Если реального назначения нет:

- [ ] не создавать фиктивный маршрут;
- [ ] не использовать href="#";
- [ ] не использовать неработающие кнопки;
- [ ] сохранить визуальную композицию;
- [ ] сделать элементы неинтерактивными либо использовать
  существующий реальный URL, если он предусмотрен.

Не создавать заглушечные страницы статей без отдельного требования.

## Запрещено

- [ ] Не создавать migrations.
- [ ] Не создавать News model.
- [ ] Не создавать NewsController.
- [ ] Не создавать News API.
- [ ] Не создавать административный CRUD.
- [ ] Не создавать CMS integration.
- [ ] Не создавать scheduler для новостей.
- [ ] Не подключать внешний news feed.

## Проверка

- [ ] Новости соответствуют Pen.
- [ ] Карточки отображаются.
- [ ] Изображения загружаются.
- [ ] Даты и тексты корректны.
- [ ] Mobile layout работает.
- [ ] Нет неработающих интерактивных элементов.
- [ ] Нет новых backend endpoints.
- [ ] Нет migrations.
- [ ] Нет новых таблиц.
- [ ] Build проходит.
