# Шаг 12 — Final Verification

## Цель

Подтвердить, что Landing V2 полностью реализован,
соответствует Pen и не нарушает работу существующего сайта.

## 1. Routing

- [ ] GET / открывает старую главную страницу.
- [ ] GET /landing открывает Landing V2.
- [ ] Нет redirect / → /landing.
- [ ] Нет конфликтующих маршрутов.
- [ ] Не изменены существующие middleware без необходимости.

## 2. Pen

- [ ] Все актуальные секции V2 реализованы.
- [ ] Порядок секций соответствует макету.
- [ ] Тексты соответствуют макету.
- [ ] Цвета соответствуют макету.
- [ ] Типографика соответствует макету.
- [ ] Отступы соответствуют макету.
- [ ] Assets соответствуют макету.
- [ ] Анимации соответствуют макету.

## 3. Navigation

- [ ] Desktop menu работает.
- [ ] Mobile menu работает.
- [ ] Anchor navigation работает.
- [ ] CTA работают.
- [ ] Footer links работают.
- [ ] Нет несуществующих маршрутов.

## 4. News

- [ ] Блок новостей отображается.
- [ ] Данные статические.
- [ ] Дизайн соответствует Pen.
- [ ] Mobile layout корректен.
- [ ] Нет неработающих ссылок.
- [ ] Нет News API.
- [ ] Нет News Model.
- [ ] Нет News migrations.
- [ ] Нет News CRUD.
- [ ] Нет CMS integration.

## 5. Responsive

Проверить:

- [ ] 320px
- [ ] 375px
- [ ] 390px
- [ ] 768px
- [ ] 1024px
- [ ] 1440px
- [ ] 1920px

Для каждого:

- [ ] Нет overflow.
- [ ] Нет сломанных сеток.
- [ ] Нет перекрытий.
- [ ] Навигация работает.
- [ ] CTA доступны.
- [ ] Изображения корректны.

## 6. Accessibility

- [ ] Keyboard navigation работает.
- [ ] Focus виден.
- [ ] Alt корректны.

- [ ] Контрастность проверена.

## 7. SEO

- [ ] Title корректен.
- [ ] Description корректен.
- [ ] H1 корректен.
- [ ] Canonical/indexing policy определена.
- [ ] Metadata главной страницы не изменены.

## 8. Build and Tests

- [ ] Production build проходит.
- [ ] Frontend tests проходят.
- [ ] Backend tests проходят.
- [ ] Linter проходит, если настроен.
- [ ] Typecheck проходит, если настроен.
- [ ] SSR работает, если используется.

- [ ] Header не изменился.

- [ ] Стили не изменились.
