# Шаг 5 — README и правила выбора Skills

## Зависимости

Перед началом должны быть завершены:

- инвентаризация;
- документация каждого skill;
- анализ Laravel skills;
- анализ frontend skills.

## Задачи

Создать:

`docs/audit/skills/README.md`

README является точкой входа в документацию Codex Skills проекта.

## Installed Skills

Создать таблицу:

| Skill | Source | Область | Когда использовать |
|---|---|---|---|

- [ ] Добавить каждый фактически установленный project skill
- [ ] Добавить source
- [ ] Добавить краткую область ответственности
- [ ] Добавить краткое условие использования
- [ ] Добавить ссылку на `<skill-name>.md`

## Skill Selection

Создать правила выбора skill по типу задачи.

Схема должна быть построена на основании завершённого анализа.

Например:

    Laravel
    ├── ...
    └── ...

    Vue
    └── ...

    Nuxt
    └── ...

    Tailwind
    ├── ...
    └── ...

Не копировать старую предполагаемую схему без проверки.

## Совместное использование

Описать подтверждённые комбинации skills.

Для каждой комбинации указать:

- тип задачи;
- используемые skills;
- ответственность каждого skill;
- необходимость совместного использования;
- известные ограничения.

## Конфликты и приоритеты

- [ ] Перечислить найденные пересечения
- [ ] Перечислить найденные конфликты
- [ ] Перечислить неоднозначности
- [ ] Указать более специализированный skill там, где это подтверждено инструкциями

Не придумывать правила приоритета.

Если однозначный приоритет определить нельзя — указать:

`Needs review`

## Project Relevance

Для каждого skill определить:

- [ ] `High`
- [ ] `Medium`
- [ ] `Low`
- [ ] `Not currently applicable`

Для оценки использовать фактический стек проекта.

Кратко объяснить причину.

## Проверка

- [ ] `README.md` создан
- [ ] Все skills присутствуют в Installed Skills
- [ ] Все ссылки ведут на существующие документы
- [ ] Skill Selection основан на фактическом анализе
- [ ] Совместное использование описано
- [ ] Конфликты описаны
- [ ] Неоднозначности обозначены
- [ ] Project Relevance описан
- [ ] Не добавлены отсутствующие skills
