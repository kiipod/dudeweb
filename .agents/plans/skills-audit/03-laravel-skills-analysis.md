# Шаг 3 — Анализ Laravel Skills

## Зависимости

Использовать документацию, созданную на предыдущем шаге.

Если установлены:

- `laravel-best-practices`
- `laravel-13-attribute-refactor`

провести их совместный анализ.

Если какой-либо skill отсутствует — зафиксировать это и анализировать
только фактически доступные skills.

## Задачи

### Область ответственности

Для каждого Laravel skill определить:

- [x] основную область ответственности;
- [x] типы задач;
- [x] поддерживаемые версии Laravel;
- [x] version-specific ограничения;
- [x] обязательные инструкции.

### Сравнение

- [x] Найти общие инструкции
- [x] Найти различия
- [x] Найти пересекающиеся рекомендации
- [x] Найти потенциальные противоречия
- [x] Найти version-specific конфликты

### Текущий проект

- [x] Определить фактическую версию Laravel проекта
- [x] Проверить совместимость каждого skill
- [x] Определить применимые инструкции
- [x] Зафиксировать неприменимые инструкции

### Выбор skill

Определить сценарии:

- [x] нужен только `laravel-best-practices`;
- [x] нужен только `laravel-13-attribute-refactor`;
- [x] нужны оба skill;
- [x] ни один skill не подходит.

### Совместное использование

Для сценариев совместного использования определить:

- [x] какую ответственность берёт каждый skill;
- [x] существует ли порядок применения;
- [x] есть ли конфликтующие инструкции.

Не придумывать правила приоритета, отсутствующие в skills.

### Документация

Обновить соответствующие:

`docs/audit/skills/<skill-name>.md`

Добавить результаты анализа в:

- `Пересечения с другими skills`
- `Приоритет инструкций`
- `Применимость к проекту`
- `Ограничения и риски`

- [x] Различия описаны

- [x] Version-specific требования проверены
- [x] Соответствие версии Laravel проекта проверено

- [x] Сценарии использования только одного skill описаны
