# Шаг 3 — Анализ Laravel Skills

## Зависимости

Использовать документацию, созданную на предыдущем шаге.

Если установлены:

- `laravel-best-practices`
- `laravel-13-attribute-refactor`

провести их совместный анализ.

Если какой-либо skill отсутствует — зафиксировать это и анализировать
только фактически доступные skills.

## Задачи

### Область ответственности

Для каждого Laravel skill определить:

- [ ] основную область ответственности;
- [ ] типы задач;
- [ ] поддерживаемые версии Laravel;
- [ ] version-specific ограничения;
- [ ] обязательные инструкции.

### Сравнение

- [ ] Найти общие инструкции
- [ ] Найти различия
- [ ] Найти пересекающиеся рекомендации
- [ ] Найти потенциальные противоречия
- [ ] Найти version-specific конфликты

### Текущий проект

- [ ] Определить фактическую версию Laravel проекта
- [ ] Проверить совместимость каждого skill
- [ ] Определить применимые инструкции
- [ ] Зафиксировать неприменимые инструкции

### Выбор skill

Определить сценарии:

- [ ] нужен только `laravel-best-practices`;
- [ ] нужен только `laravel-13-attribute-refactor`;
- [ ] нужны оба skill;
- [ ] ни один skill не подходит.

### Совместное использование

Для сценариев совместного использования определить:

- [ ] какую ответственность берёт каждый skill;
- [ ] существует ли порядок применения;
- [ ] есть ли конфликтующие инструкции.

Не придумывать правила приоритета, отсутствующие в skills.

### Документация

Обновить соответствующие:

`docs/audit/skills/<skill-name>.md`

Добавить результаты анализа в:

- `Пересечения с другими skills`
- `Приоритет инструкций`
- `Применимость к проекту`
- `Ограничения и риски`

## Проверка

- [ ] Все фактически установленные Laravel skills проанализированы
- [ ] Области ответственности разделены
- [ ] Общие инструкции найдены
- [ ] Различия описаны
- [ ] Потенциальные конфликты описаны
- [ ] Version-specific требования проверены
- [ ] Соответствие версии Laravel проекта проверено
- [ ] Сценарии совместного использования описаны
- [ ] Сценарии использования только одного skill описаны
- [ ] Документация skills обновлена
