# Шаг 7 — Финальная проверка документации Codex Skills

На этом шаге новая документация по возможностям skills не создаётся.

Исправляются только проблемы, обнаруженные во время финальной проверки.

## 1. Инвентаризация

Выполнить:

    npx skills list

Проверить:

- [ ] Фактический список `.agents/skills/`
- [ ] Каждый project skill присутствует в `inventory.md`
- [ ] Каждый project skill присутствует в `README.md`
- [ ] Для каждого project skill существует отдельный `.md`
- [ ] Отсутствующие skills не задокументированы как установленные

## 2. Документация skills

Для каждого `<skill-name>.md`:

- [ ] Информация основана на фактическом `SKILL.md`
- [ ] Нет выдуманных возможностей
- [ ] Указан реальный путь
- [ ] Указан source, если доступен
- [ ] Описано назначение
- [ ] Описано, когда использовать
- [ ] Описано, когда не использовать
- [ ] Описаны основные возможности
- [ ] Описаны обязательные инструкции
- [ ] Описан workflow
- [ ] Описаны дополнительные ресурсы
- [ ] Описана применимость к проекту
- [ ] Описаны пересечения
- [ ] Описаны ограничения и риски
- [ ] Указаны version-specific ограничения
- [ ] Исходный `SKILL.md` не скопирован целиком

## 3. Дополнительные ресурсы

Для каждого skill:

- [ ] `references/` учтены
- [ ] `examples/` учтены
- [ ] `scripts/` учтены
- [ ] templates учтены
- [ ] другие существенные ресурсы учтены

Проверять только реально существующие ресурсы.

## 4. Laravel Skills

- [ ] Laravel skills отдельно проанализированы
- [ ] Области ответственности определены
- [ ] Пересечения описаны
- [ ] Version-specific требования проверены
- [ ] Соответствие текущей версии Laravel проверено
- [ ] Сценарии совместного использования описаны

## 5. Frontend Skills

- [ ] Frontend skills отдельно проанализированы
- [ ] Области ответственности определены
- [ ] Пересечения описаны
- [ ] Конфликты описаны
- [ ] Сценарии совместного использования описаны
- [ ] Наиболее специализированные skills определены там, где это возможно

## 6. README

Проверить:

`docs/audit/skills/README.md`

- [ ] Installed Skills содержит полный актуальный список
- [ ] Ссылки ведут на существующие документы
- [ ] Skill Selection актуален
- [ ] Совместное использование описано
- [ ] Конфликты и приоритеты описаны
- [ ] Project Relevance описан
- [ ] Codex Availability описан
- [ ] AGENTS.md Recommendations присутствуют, если необходимы

## 7. Discoverability

- [ ] `.agents/skills/` сопоставлен с `npx skills list`
- [ ] Наличие `SKILL.md` проверено
- [ ] Metadata проверены
- [ ] Codex availability зафиксирована
- [ ] Проблемы обнаружения зафиксированы

Убедиться, что документация различает:

- [ ] installed
- [ ] discovered by tooling
- [ ] applicable to task
- [ ] actually selected during execution

## 8. Ограничения

Убедиться, что не изменены:

- [ ] `.agents/skills/**`
- [ ] `AGENTS.md`
- [ ] код приложения
- [ ] конфигурация Codex
- [ ] зависимости проекта

## 9. Git verification

Выполнить:

    git status --short

и:

    git diff -- docs/audit/skills

Проверить:

- [ ] Изменения текущей задачи находятся только в `docs/audit/skills/**`
- [ ] Пользовательские изменения вне этой директории не изменены
- [ ] Пользовательские изменения не откатывались

## 10. Definition of Done

Задача считается выполненной, когда:

- [ ] Все фактически установленные project skills обнаружены
- [ ] Каждый `SKILL.md` полностью проанализирован
- [ ] Существенные дополнительные ресурсы изучены
- [ ] Для каждого skill создан отдельный документ
- [ ] Создан `docs/audit/skills/README.md`
- [ ] Для каждого skill понятно, когда его использовать
- [ ] Для каждого skill понятно, когда его не использовать
- [ ] Возможные комбинации skills описаны
- [ ] Пересечения и потенциальные конфликты зафиксированы
- [ ] Доступность skills для Codex проверена
- [ ] Документация соответствует текущему состоянию проекта
- [ ] Исходные skills не изменены
- [ ] `AGENTS.md` не изменён
- [ ] Код приложения не изменён
- [ ] Verification успешно пройден

После успешного завершения обновить:

`.agent/plans/skills-audit/00-overview.md`

и отметить:

`Шаг 7 — Финальная проверка документации`

как выполненный.
