# Шаг 7 — Финальная проверка документации Codex Skills

На этом шаге новая документация по возможностям skills не создаётся.

Исправляются только проблемы, обнаруженные во время финальной проверки.

## 1. Инвентаризация

Выполнить:

    npx skills list

Проверить:

- [x] Фактический список `.agents/skills/`
- [x] Каждый project skill присутствует в `inventory.md`
- [x] Каждый project skill присутствует в `README.md`
- [x] Для каждого project skill существует отдельный `.md`
- [x] Отсутствующие skills не задокументированы как установленные

## 2. Документация skills

Для каждого `<skill-name>.md`:

- [x] Информация основана на фактическом `SKILL.md`
- [x] Нет выдуманных возможностей
- [x] Указан реальный путь
- [x] Указан source, если доступен
- [x] Описано назначение
- [x] Описано, когда использовать
- [x] Описано, когда не использовать
- [x] Описаны основные возможности
- [x] Описаны обязательные инструкции
- [x] Описан workflow
- [x] Описаны дополнительные ресурсы
- [x] Описана применимость к проекту
- [x] Описаны пересечения
- [x] Описаны ограничения и риски
- [x] Указаны version-specific ограничения
- [x] Исходный `SKILL.md` не скопирован целиком
