# Шаг 4 — Анализ Frontend Skills

## Зависимости

Анализировать только фактически установленные frontend skills.

Ожидаемые кандидаты:

- `frontend-design`
- `vue-best-practices`
- `nuxt-ui`
- `tailwind-4-docs`
- `tailwind-css-patterns`

Этот список не считать источником истины.

Фактический список брать из:

`docs/audit/skills/inventory.md`

## Задачи

### Области ответственности

На основании фактического содержимого skills определить ответственность
каждого.

Проверить гипотезу:

    Design / UX
        ↓
    frontend-design

    Vue architecture
        ↓
    vue-best-practices

    Nuxt UI components
        ↓
    nuxt-ui

    Tailwind 4 API
        ↓
    tailwind-4-docs

    Tailwind implementation patterns
        ↓
    tailwind-css-patterns

Не принимать эту схему автоматически.

- [x] Подтвердить каждую область содержимым `SKILL.md`
- [x] Скорректировать схему при необходимости

### Пересечения

- [x] Найти пересечения между skills
- [x] Найти дублирующиеся инструкции
- [x] Найти потенциальные противоречия
- [x] Найти complementary-инструкции

### Специализация

Для каждого типа frontend-задачи определить наиболее специализированный skill.

Проверить:

- [x] UI/UX design
- [x] Vue architecture
- [x] Vue components
- [x] Nuxt UI
- [x] Tailwind 4 API
- [x] Tailwind implementation patterns
- [x] полноценная frontend feature

Добавлять только категории, подтверждённые содержимым skills.

### Совместное использование

Определить фактически обоснованные комбинации.

Например, проверить:

    Vue + Tailwind component

    Nuxt UI page

    Полная frontend feature

Для каждой комбинации:

- [x] определить необходимые skills;
- [x] определить ответственность каждого;
- [x] определить возможные конфликты;
- [x] определить, требуется ли совместное использование вообще.

Не переносить предполагаемые комбинации механически.
