# Шаг 1 — Инвентаризация Codex Skills

На этом шаге проводится только инвентаризация.

Подробный анализ инструкций skills выполняется на следующем шаге.

## Задачи

### Файловая система

- [x] Проверить содержимое `.agents/skills/`
- [x] Получить полный список каталогов skills
- [x] Для каждого каталога найти `SKILL.md`
- [x] Зафиксировать фактический путь каждого skill

### Дополнительные ресурсы

Для каждого skill проверить наличие:

- [x] `references/`
- [x] `examples/`
- [x] `scripts/`
- [x] templates
- [x] дополнительных Markdown-файлов
- [x] конфигурационных файлов
- [x] других ресурсов

На этом шаге не требуется подробно анализировать содержимое ресурсов.

Необходимо только зафиксировать их наличие.

### Skills CLI

Выполнить:

    npx skills list

- [x] Получить список skills
- [x] Зафиксировать source каждого project skill, если доступен
- [x] Зафиксировать указанных CLI Agents
- [x] Определить, какие skills помечены как доступные Codex

### Сопоставление

Сопоставить:

    .agents/skills/

с:

    npx skills list

Для каждого skill определить:

- [x] присутствует ли каталог;
- [x] существует ли `SKILL.md`;
- [x] обнаруживается ли skill через CLI;
- [x] указан ли Codex среди Agents;
- [x] известен ли source.

### Расхождения

Зафиксировать:

- [x] каталог существует, но CLI не обнаруживает skill;
- [x] CLI показывает skill, отсутствующий в `.agents/skills/`;
- [x] отсутствует `SKILL.md`;
- [x] отсутствуют или некорректны metadata;
- [x] Codex отсутствует среди Agents;
- [x] source определить невозможно.

### Документация

Создать:

`docs/audit/skills/inventory.md`

Добавить таблицу:

| Skill | Path | Source | SKILL.md | Codex | Resources | Status |
|---|---|---|---|---|---|---|

Использовать статусы:

- `Available`
- `Missing`
- `Invalid`
- `Needs review`

Отдельно добавить раздел:

`## Расхождения`

Если расхождений нет — явно это указать.

## Проверка

- [x] Фактический список `.agents/skills/` получен
- [x] `npx skills list` выполнен
- [x] Результаты сопоставлены
- [x] Для каждого skill найден `SKILL.md`
- [x] Для каждого skill определён source, если доступен
- [x] Для каждого skill проверена доступность Codex
- [x] Дополнительные ресурсы перечислены
- [x] Все расхождения зафиксированы
- [x] `docs/audit/skills/inventory.md` создан
- [x] `.agents/skills/**` не изменён
- [x] Код приложения не изменён
