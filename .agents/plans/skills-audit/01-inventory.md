# Шаг 1 — Инвентаризация Codex Skills

На этом шаге проводится только инвентаризация.

Подробный анализ инструкций skills выполняется на следующем шаге.

## Задачи

### Файловая система

- [ ] Проверить содержимое `.agents/skills/`
- [ ] Получить полный список каталогов skills
- [ ] Для каждого каталога найти `SKILL.md`
- [ ] Зафиксировать фактический путь каждого skill

### Дополнительные ресурсы

Для каждого skill проверить наличие:

- [ ] `references/`
- [ ] `examples/`
- [ ] `scripts/`
- [ ] templates
- [ ] дополнительных Markdown-файлов
- [ ] конфигурационных файлов
- [ ] других ресурсов

На этом шаге не требуется подробно анализировать содержимое ресурсов.

Необходимо только зафиксировать их наличие.

### Skills CLI

Выполнить:

    npx skills list

- [ ] Получить список skills
- [ ] Зафиксировать source каждого project skill, если доступен
- [ ] Зафиксировать указанных CLI Agents
- [ ] Определить, какие skills помечены как доступные Codex

### Сопоставление

Сопоставить:

    .agents/skills/

с:

    npx skills list

Для каждого skill определить:

- [ ] присутствует ли каталог;
- [ ] существует ли `SKILL.md`;
- [ ] обнаруживается ли skill через CLI;
- [ ] указан ли Codex среди Agents;
- [ ] известен ли source.

### Расхождения

Зафиксировать:

- [ ] каталог существует, но CLI не обнаруживает skill;
- [ ] CLI показывает skill, отсутствующий в `.agents/skills/`;
- [ ] отсутствует `SKILL.md`;
- [ ] отсутствуют или некорректны metadata;
- [ ] Codex отсутствует среди Agents;
- [ ] source определить невозможно.

### Документация

Создать:

`docs/audit/skills/inventory.md`

Добавить таблицу:

| Skill | Path | Source | SKILL.md | Codex | Resources | Status |
|---|---|---|---|---|---|---|

Использовать статусы:

- `Available`
- `Missing`
- `Invalid`
- `Needs review`

Отдельно добавить раздел:

`## Расхождения`

Если расхождений нет — явно это указать.

## Проверка

- [ ] Фактический список `.agents/skills/` получен
- [ ] `npx skills list` выполнен
- [ ] Результаты сопоставлены
- [ ] Для каждого skill найден `SKILL.md`
- [ ] Для каждого skill определён source, если доступен
- [ ] Для каждого skill проверена доступность Codex
- [ ] Дополнительные ресурсы перечислены
- [ ] Все расхождения зафиксированы
- [ ] `docs/audit/skills/inventory.md` создан
- [ ] `.agents/skills/**` не изменён
- [ ] Код приложения не изменён
