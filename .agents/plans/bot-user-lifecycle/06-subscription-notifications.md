# Шаг 6 — Уведомление об окончании подписки

## Цель

За один день до окончания подписки отправлять пользователю Telegram
notification.

## Источник даты

Использовать актуальный `expireAt` Remnawave.

Не использовать устаревшее локальное значение, если Remnawave предоставляет
актуальное состояние.

## Условие

Когда до окончания подписки остаётся 1 день:

- [ ] отправить reminder.

Смысл:

> Ваша подписка скоро закончится. Не забудьте продлить её.

Фактический текст оформить согласно существующему стилю бота.

## Scheduler

Проверить существующие:

- Laravel Scheduler;
- Commands;
- Jobs;
- Queue.

Использовать существующую архитектуру.

Не создавать второй scheduler-механизм.

## Идемпотентность

Reminder должен отправляться один раз для конкретного окончания подписки.

Проверить:

- [ ] повторный scheduler run не дублирует сообщение;
- [ ] restart приложения не приводит к повторной рассылке;
- [ ] после продления новый `expireAt` может получить новый reminder в будущем.

Выбрать механизм согласно существующей модели данных.

## Исключения

Проверить необходимость notification для:

- [ ] FAMILY
- [ ] FRIENDS
- [ ] DISABLED
- [ ] LIMITED
- [ ] EXPIRED

Для бессрочной FAMILY / FRIENDS reminder об окончании не должен отправляться,
если у них действительно отсутствует конечный срок.

## Tests

- [ ] expireAt > 1 дня → нет reminder
- [ ] остаётся 1 день → reminder
- [ ] повторная проверка → без duplicate
- [ ] после renewal новый expiration учитывается
- [ ] бессрочный пользователь не получает reminder
