# Шаг 3 — Frontend Audit

## Цель

Провести технический аудит frontend-реализации независимо
от визуального соответствия Pen.

Выявить ошибки, дублирование, неоптимальные компоненты
и проблемы пользовательского взаимодействия.

## Зависимости

- docs/audit/project-audit/project-inventory.md
- docs/audit/project-audit/pen-design.md
- docs/audit/project-audit/findings.md

## Архитектура

- [ ] Изучить frontend entry points.
- [ ] Изучить routing.
- [ ] Проверить организацию компонентов.
- [ ] Проверить composables/hooks.
- [ ] Проверить управление состоянием.
- [ ] Проверить API-клиенты.
- [ ] Проверить обработку ошибок.
- [ ] Проверить повторное использование компонентов.

## Code Review

Найти:

- [ ] Дублирующиеся компоненты.
- [ ] Слишком большие компоненты.
- [ ] Сложные условные конструкции.
- [ ] Неиспользуемые props.
- [ ] Неиспользуемые imports.
- [ ] Неиспользуемые зависимости.
- [ ] Мёртвый код.
- [ ] Дублирование CSS.
- [ ] Избыточные watchers/effects.
- [ ] Неоптимальные вычисления.
- [ ] Лишние запросы к API.

## Forms

- [ ] Проверить валидацию.
- [ ] Проверить отображение ошибок.
- [ ] Проверить loading states.
- [ ] Проверить защиту от повторной отправки.
- [ ] Проверить disabled states.
- [ ] Проверить поведение после успешного submit.
- [ ] Проверить сохранение пользовательского ввода при ошибках.

## Navigation

- [ ] Проверить все внутренние ссылки.
- [ ] Проверить отсутствующие маршруты.
- [ ] Проверить редиректы.
- [ ] Проверить работу browser back/forward.
- [ ] Проверить состояния авторизации.
- [ ] Проверить обработку 401/403/404.

## Accessibility

- [ ] Проверить HTML-семантику.
- [ ] Проверить labels.
- [ ] Проверить клавиатурную навигацию.
- [ ] Проверить focus visibility.
- [ ] Проверить управление модальными окнами.
- [ ] Проверить aria-атрибуты.
- [ ] Проверить контрастность.
- [ ] Проверить prefers-reduced-motion.

## Browser Behavior

Если доступен браузер:

- [ ] Проверить console errors.
- [ ] Проверить network errors.
- [ ] Проверить mobile viewport.
- [ ] Проверить touch events.
- [ ] Проверить scroll behavior.
- [ ] Проверить hydration/SSR, если используется.
- [ ] Проверить отсутствие memory leaks в очевидных сценариях.

Если браузер недоступен, отметить непроверенные сценарии.
