# Шаг 2 — Pen Design Audit

## Цель

Проверить соответствие реализованного frontend макетам Pen.

Проверять не только визуальное сходство, но и интерактивность,
адаптивность и пользовательские сценарии.

## Зависимости

- docs/audit/project-audit/project-inventory.md
- docs/audit/project-audit/findings.md
- существующие Pen-макеты

## Дизайн-система

Проверить:

- [ ] Цвета.
- [ ] Шрифты.
- [ ] Размеры текста.
- [ ] Line-height.
- [ ] Отступы.
- [ ] Border radius.
- [ ] Shadows.
- [ ] Контейнеры.
- [ ] Grid/Flex layouts.
- [ ] Иконки.
- [ ] Кнопки.
- [ ] Формы.
- [ ] Карточки.
- [ ] Модальные окна.

Не рекомендовать произвольные значения, если они определены в Pen.

## Mobile-first

Проверить viewport:

- 320px
- 375px
- 390px
- 768px
- 1024px
- 1440px

Дополнительно проверить проблемные промежуточные ширины.

Для каждого viewport:

- [ ] Контент не выходит за экран.
- [ ] Нет горизонтального overflow.
- [ ] Текст читаем.
- [ ] Кнопки доступны.
- [ ] Навигация работает.
- [ ] Изображения не ломают layout.
- [ ] Модальные окна доступны.
- [ ] Touch-интерактивность работает.
