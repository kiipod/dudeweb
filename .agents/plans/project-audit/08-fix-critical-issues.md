# Шаг 8 — Fix Critical Issues

## Цель

Исправить подтверждённые проблемы приоритетов P0 и P1.

Не выполнять несвязанный рефакторинг.

## Условия начала

- [ ] Шаги 01–07 завершены.
- [ ] findings.md актуален.
- [ ] Приоритеты проверены.
- [ ] Пользователь подтвердил переход к исправлениям.
- [ ] Определён scope.

## Подготовка

- [ ] Прочитать все P0/P1 findings.
- [ ] Проверить связанные отчёты.
- [ ] Проверить существующие тесты.
- [ ] Проверить зависимости между проблемами.
- [ ] Определить порядок исправления.

## Для каждого Finding

### Before Fix

- [ ] Прочитать описание.
- [ ] Проверить evidence.
- [ ] Воспроизвести проблему.
- [ ] Проверить все затронутые места.
- [ ] Определить минимальное безопасное исправление.
- [ ] Добавить regression test, если возможно.

### Implementation

- [ ] Перевести статус в IN_PROGRESS.
- [ ] Исправить первопричину.
- [ ] Не менять несвязанные компоненты.
- [ ] Сохранить бизнес-логику.
- [ ] Проверить backward compatibility.
- [ ] Не отключать защитные механизмы.

### Verification

- [ ] Запустить regression test.
- [ ] Запустить связанные тесты.
- [ ] Проверить исходный сценарий.
- [ ] Проверить соседние сценарии.
- [ ] Выполнить security recheck, если применимо.

### Resolution

- [ ] Указать изменённые файлы.
- [ ] Указать commit.
- [ ] Зафиксировать результат проверки.
- [ ] Перевести в FIXED.
- [ ] Перевести в VERIFIED только после успешной проверки.

## Blocked Issues

Если исправление невозможно:

- [ ] Указать причину.
- [ ] Указать недостающую зависимость.
- [ ] Указать риск.
- [ ] Перевести в BLOCKED.
- [ ] Не скрывать проблему из отчёта.

ACCEPTED_RISK разрешён только после явного согласования.

## Проверка

- [ ] Все согласованные P0 обработаны.
- [ ] Все согласованные P1 обработаны.
- [ ] Нерешённые проблемы документированы.
- [ ] Regression tests выполнены.
- [ ] findings.md обновлён.
- [ ] Нет несвязанных изменений.

## Commit

Использовать отдельные логические commits:

fix: resolve SEC-001 ...
fix: resolve BE-002 ...

Не объединять несвязанные исправления в один commit.
