# Интеграция YooKassa

> **Область:** внедрение оплаты через YooKassa.
>
> Только backend и Telegram-бот.

## Источник истины

Интеграция YooKassa выполняется через:

`yoomoney/yookassa-sdk-php:3.13.2`

Перед использованием классов или методов SDK необходимо сверяться с документацией версии 3.13.2.

### Тестовые платежи

Документация по проведению тестовых платежей через тестовый магазин YooKassa
находится в:

`docs/yookassa/test-payment.md`

Документ является источником истины для:

- настройки тестового магазина;
- тестовых платёжных данных;
- проведения тестовой оплаты;
- проверки успешного платежа;
- проверки неуспешного платежа;
- проверки сценариев возврата;
- проверки webhook в тестовом окружении.

При выполнении тестовых платежей необходимо использовать инструкции
из `docs/yookassa/test-payment.md`.

Не использовать реальные платёжные данные для проверки интеграции.

## Обязательный контекст

Перед началом реализации прочитать:

- `docs/audit/models.md`
- `docs/audit/services.md`
- `docs/audit/api.md`

Результаты аудита являются источником истины о существующей архитектуре проекта.

## Правила

- существующий код переиспользовать;
- не создавать сущности, если аналогичные уже существуют;
- не дублировать существующую бизнес-логику;
- расчёт скидок должен использовать существующую механику;
- работа с Remnawave должна использовать существующие Handler;
- Telegram-интеграция должна использовать существующую архитектуру бота;
- каждый шаг выполняется отдельно;
- после каждого шага выполняется блок **Проверка**;
- Commit выполняется только после успешной проверки.
- Тестовые платежи выполнять согласно `docs/yookassa/test-payment.md`;
- Для проверки интеграции использовать тестовый магазин YooKassa;
- Не использовать реальные платёжные данные при разработке и тестировании;

После выполнения шага:

1. выполнить все пункты **Проверка**;
2. отметить выполненные микрозадачи;
3. обновить этот файл;
4. выполнить Commit;
5. только после этого переходить к следующему шагу.
