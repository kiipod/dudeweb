# Шаг 7 — YooKassa Webhook: инфраструктура

На этом шаге реализуется только транспортный слой webhook.

Бизнес-логика обработки успешного платежа реализуется на следующем шаге.

## Задачи

### Route

- [ ] Добавить `POST /webhooks/yookassa`
- [ ] Маршрут не должен использовать `auth`
- [ ] Исключить маршрут из CSRF-защиты

### Controller

- [ ] Найти существующий WebhookController
- [ ] Если отсутствует — создать его
- [ ] Добавить метод обработки YooKassa webhook
- [ ] Получать raw request body
- [ ] Передавать обработку в PaymentService

### Source validation

- [ ] Реализовать проверку источника согласно документации YooKassa
- [ ] Не хардкодить неподтверждённые диапазоны IP
- [ ] Не доверять данным webhook до прохождения предусмотренной проверки

### Response

- [ ] Валидный обработанный запрос возвращает HTTP 200
- [ ] Ошибки обработки логируются
- [ ] Невалидный источник получает 403

## Проверка

- [ ] `php artisan route:list` содержит `/webhooks/yookassa`
- [ ] POST без CSRF token не возвращает 419
- [ ] Webhook доступен без авторизации
- [ ] raw body передаётся в PaymentService
- [ ] невалидный источник отклоняется
