На этом шаге реализуется только транспортный слой webhook.

Бизнес-логика обработки успешного платежа реализуется на следующем шаге.

- [x] Добавить `POST /webhooks/yookassa`

### Controller

- [x] Найти существующий WebhookController

### Source validation

- [x] Реализовать проверку источника согласно документации YooKassa

### Response

- [x] Валидный обработанный запрос возвращает HTTP 200
- [x] Ошибки обработки логируются
