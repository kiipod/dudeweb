## Использование

Для каждого столбца выполнить поиск по проекту.

Классифицировать:

- `REQUIRED`
- `AUDIT`
- `DERIVED`
- `DUPLICATED`
- `UNUSED`
- `UNKNOWN`

### REQUIRED

Необходим для работы приложения.

### AUDIT

Может не участвовать непосредственно в бизнес-логике, но нужен для истории
платежей, диагностики или поддержки.

### DERIVED

Может быть вычислен из других данных.

Не считать поле автоматически лишним только потому, что оно вычисляемое.

### DUPLICATED

Хранит данные, уже существующие в другом месте.

Проверить, требуется ли snapshot значения на момент платежа.

### UNUSED

Нет реальных reads/writes и отсутствует необходимость хранения.

### UNKNOWN

Назначение невозможно определить однозначно.

Такое поле автоматически не удалять.

## Особое внимание

Проверить необходимость хранения:

- YooKassa payment ID;
- локального статуса;
- amount;
- currency;
- confirmation URL;
- source;
- Product reference;
- User reference;
- Promocode reference;
- metadata;
- timestamps;
- cancellation information, если она сохраняется.

Не считать этот список фактическим schema.

Проверять реальные поля проекта.
