## Migration report

Обновить:

`docs/remnawave/migration.md`

Для каждого элемента итоговый статус должен быть одним из:

- `MIGRATED`
- `UNCHANGED`
- `REMOVED`
- `BLOCKED`

Для `BLOCKED` обязательно указать причину.
