# Шаг 4 — Обновление мест использования Remnawave API

## Зависимости

Перед началом прочитать:

- `docs/remnawave/migration.md`

DTO и Handler к этому моменту должны соответствовать новому API.

## Задачи

### Handler usages

Для каждого изменённого Handler:

- [ ] найти все места вызова;
- [ ] проверить передаваемые аргументы;
- [ ] удалить устаревшие аргументы;
- [ ] добавить новые обязательные аргументы;
- [ ] обновить порядок / структуру аргументов при необходимости;
- [ ] проверить обработку результата.

### DTO usages

- [ ] Найти обращения к удалённым полям
- [ ] Найти обращения к переименованным полям
- [ ] Обновить обращения на новую структуру
- [ ] Проверить nullable-поля перед использованием
- [ ] Проверить работу с изменёнными Enum
- [ ] Проверить работу с изменёнными вложенными структурами

### Основные сценарии

Проверить существующие сценарии Remnawave:

- [ ] создание пользователя;
- [ ] получение пользователя;
- [ ] обновление пользователя;
- [ ] удаление / отключение пользователя, если используется;
- [ ] получение subscription;
- [ ] работа с `subscriptionUrl`;
- [ ] работа с `expireAt`;
- [ ] изменение статуса;
- [ ] работа с traffic limit;
- [ ] получение использованного трафика;
- [ ] продление подписки.

Проверять только реально существующие в проекте сценарии.

### Удалённый код

- [ ] Найти Handler старого API, которые больше нигде не используются
- [ ] Найти DTO старого API, которые больше нигде не используются
- [ ] Удалить только действительно неиспользуемые классы
- [ ] Проверить импорты
- [ ] Проверить references после удаления

### Бизнес-логика

- [ ] Не изменять бизнес-правила без необходимости
- [ ] Не менять поведение приложения, если изменение не вызвано новым API
- [ ] Если новый API больше не позволяет сохранить старое поведение — зафиксировать это в `migration.md`

## Проверка

- [ ] Нет обращений к удалённым DTO-полям
- [ ] Нет вызовов Handler со старой сигнатурой
- [ ] Нет использования удалённых endpoint
- [ ] Все новые required-параметры передаются
- [ ] Nullable значения обрабатываются безопасно
- [ ] Неиспользуемые legacy DTO удалены
- [ ] Неиспользуемые legacy Handler удалены
- [ ] Основные Remnawave-сценарии используют новый контракт
