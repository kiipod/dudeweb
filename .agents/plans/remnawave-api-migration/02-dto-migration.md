# Шаг 2 — Миграция Remnawave DTO

## Зависимости

Перед началом прочитать:

- `docs/remnawave/api-1.json`
- `docs/remnawave/migration.md`

Изменять только DTO со статусами:

- `MODIFIED`
- `REPLACED`

DTO со статусом `UNCHANGED` не изменять без необходимости.

## Задачи

### Request DTO

Для каждого изменённого request DTO:

- [x] найти соответствующую request schema в `api-1.json`;
- [x] удалить поля, отсутствующие в новом API;
- [x] добавить новые обязательные поля;
- [x] добавить новые необходимые optional-поля;
- [x] обновить переименованные поля;
- [x] обновить PHP-типы;
- [x] обновить nullable-типы;
- [x] обновить массивы;
- [x] обновить вложенные DTO;
- [x] обновить Enum;
- [x] проверить сериализацию в request payload.

### Response DTO

Для каждого изменённого response DTO:

- [x] найти соответствующую response schema;
- [x] удалить поля, отсутствующие в response;
- [x] добавить новые используемые поля;
- [x] обновить названия полей;
- [x] обновить PHP-типы;
- [x] обновить nullable-типы;
- [x] обновить массивы;
- [x] обновить вложенные DTO;
- [x] обновить Enum;
- [x] проверить создание DTO из response.

### Новые структуры

Если новый API содержит вложенную структуру, которой раньше не было:

- [x] проверить, соответствует ли она существующему DTO;
- [x] переиспользовать существующий DTO, если контракт совпадает;
- [x] создать новый DTO только если отдельная структура действительно существует в API;
- [x] не создавать DTO для полей, которые приложение не использует, если архитектура проекта этого не требует.

### Удалённые DTO

Для DTO со статусом `REMOVED`:

- [x] проверить все места использования;
- [x] не удалять DTO до миграции зависимого кода;
- [x] пометить DTO для удаления на шаге 4.

### Совместимость

- [x] Найти обращения к удалённым свойствам DTO
- [x] Найти обращения к переименованным свойствам
- [x] Составить список мест, требующих изменения на шаге 4

## Проверка

- [x] Все `MODIFIED` DTO соответствуют `api-1.json`
- [x] Все `REPLACED` DTO адаптированы
- [x] Required-поля соответствуют документации
- [x] Nullable соответствует документации
- [x] PHP-типы соответствуют API
- [x] Enum соответствуют API
- [x] Сериализация request DTO соответствует schema
- [x] Десериализация response DTO соответствует schema
- [x] DTO со статусом `UNCHANGED` не изменены без причины
- [x] Не добавлены поля, отсутствующие в API
