# Шаг 2 — Миграция Remnawave DTO

## Зависимости

Перед началом прочитать:

- `docs/remnawave/api-1.json`
- `docs/remnawave/migration.md`

Изменять только DTO со статусами:

- `MODIFIED`
- `REPLACED`

DTO со статусом `UNCHANGED` не изменять без необходимости.

## Задачи

### Request DTO

Для каждого изменённого request DTO:

- [ ] найти соответствующую request schema в `api-1.json`;
- [ ] удалить поля, отсутствующие в новом API;
- [ ] добавить новые обязательные поля;
- [ ] добавить новые необходимые optional-поля;
- [ ] обновить переименованные поля;
- [ ] обновить PHP-типы;
- [ ] обновить nullable-типы;
- [ ] обновить массивы;
- [ ] обновить вложенные DTO;
- [ ] обновить Enum;
- [ ] проверить сериализацию в request payload.

### Response DTO

Для каждого изменённого response DTO:

- [ ] найти соответствующую response schema;
- [ ] удалить поля, отсутствующие в response;
- [ ] добавить новые используемые поля;
- [ ] обновить названия полей;
- [ ] обновить PHP-типы;
- [ ] обновить nullable-типы;
- [ ] обновить массивы;
- [ ] обновить вложенные DTO;
- [ ] обновить Enum;
- [ ] проверить создание DTO из response.

### Новые структуры

Если новый API содержит вложенную структуру, которой раньше не было:

- [ ] проверить, соответствует ли она существующему DTO;
- [ ] переиспользовать существующий DTO, если контракт совпадает;
- [ ] создать новый DTO только если отдельная структура действительно существует в API;
- [ ] не создавать DTO для полей, которые приложение не использует, если архитектура проекта этого не требует.

### Удалённые DTO

Для DTO со статусом `REMOVED`:

- [ ] проверить все места использования;
- [ ] не удалять DTO до миграции зависимого кода;
- [ ] пометить DTO для удаления на шаге 4.

### Совместимость

- [ ] Найти обращения к удалённым свойствам DTO
- [ ] Найти обращения к переименованным свойствам
- [ ] Составить список мест, требующих изменения на шаге 4

## Проверка

- [ ] Все `MODIFIED` DTO соответствуют `api-1.json`
- [ ] Все `REPLACED` DTO адаптированы
- [ ] Required-поля соответствуют документации
- [ ] Nullable соответствует документации
- [ ] PHP-типы соответствуют API
- [ ] Enum соответствуют API
- [ ] Сериализация request DTO соответствует schema
- [ ] Десериализация response DTO соответствует schema
- [ ] DTO со статусом `UNCHANGED` не изменены без причины
- [ ] Не добавлены поля, отсутствующие в API
