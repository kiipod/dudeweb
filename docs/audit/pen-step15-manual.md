# Шаг 15 — ручной протокол приёмки

Статус на 2026-10-21: владелец согласился выполнить протокол; результатов ещё
нет. Автоматические Playwright input assertions не заменяют эти проверки.

Использовать обычное окно браузера с приложением, физическую клавиатуру и
собственный тестовый аккаунт. Для screen reader указать сочетание ОС, браузера
и AT: например, Windows + Chrome + NVDA либо macOS + Safari + VoiceOver.
Пароли, reset tokens и персональные ссылки подключения в отчёт не копировать.

| ID | Проверка | Ожидаемый результат | Результат владельца |
| --- | --- | --- | --- |
| M-01 | На `/login`, `/register`, `/forgot-password` и странице нового пароля пройти Tab/Shift+Tab; Enter на видимости пароля и submit | Порядок логичен, виден фокус, кнопка видимости сообщает действие и сохраняет фокус, заполнение и отправка доступны клавиатурой | Открыто |
| M-02 | На auth-форме получить ошибку валидации; прочитать поле и ошибку screen reader | Объявляются label, тип поля, invalid state и текст ошибки; ошибка не теряется после исправления | Открыто |
| M-03 | На landing открыть меню; в кабинете открыть «Ещё» и промокод на узком экране; промокод на desktop | Фокус внутри overlay, фон недоступен; Tab и Shift+Tab не уходят под overlay; Escape закрывает; фокус возвращается к кнопке | Открыто |
| M-04 | Перейти по skip link на landing и в кабинете; пройти навигацию и заголовки screen reader | Основной контент достигается сразу; объявляются названия разделов и текущая страница; один основной landmark; heading order понятен | Открыто |
| M-05 | Проверить подписку, подключение, приглашения/условия, поддержку/диалог и профиль screen reader | Читаются названия controls, selected periods/platform/theme, таблица наград и сообщения; декоративные SVG не попадают в чтение | Открыто |
| M-06 | В копировании ссылки и доступной форме вызвать success/error; проверить pending/terminal payment state только на тестовом платеже | Status/error объявляется один раз и соответствует результату; pending не объявляется успешной оплатой | Открыто |
| M-07 | Browser zoom 200% и 400% при desktop окне 1280px или шире; обе темы; проверить формы, кабинет, меню и промокод | Контент reflow без потери текста/действий; возможна вертикальная прокрутка; fixed/sticky chrome не закрывает фокус | Открыто |
| M-08 | Text-only zoom 200%, если браузер поддерживает; проверить длинный текст и последние действия на странице | Текст читается полностью, поля/кнопки доступны, содержимое не обрезано фиксированными высотами | Открыто |
| M-09 | В обычной видимой вкладке Hero до hover, затем hover/drag/release; mobile/tablet и background → return | Desktop sphere движется до наведения, отвечает на мышь и продолжает движение после инерции; орбиты занимают секцию; фон/невидимая область останавливают движение без скачка при возврате | Открыто |
| M-10 | Включить системный reduced motion и high contrast/forced colors | Декор статичен либо скрыт, controls и фокус читаемы; функции и тексты сохранены | Открыто |
| M-11 | Физическое touch-устройство: landing menu, «Ещё», selectors, copy/share; portrait/landscape, нижний край экрана | Нет действий только по hover, элементы достижимы, safe areas и клавиатура устройства не закрывают последние действия | Открыто |
| M-12 | Согласованный тестовый email: запрос reset через прямой production-like SMTP; открыть ссылку и изменить тестовый пароль | Письмо доставлено вне Mailpit/log, From верен, URL/домен верны, ссылка работает один раз; пароль не попадает в письмо | Открыто — адрес и SMTP не предоставлены |

Шаблон ответа:

```text
ОС / браузер / screen reader / устройство:
M-01 … M-12: пройдено / проблема / не проверено
Для проблемы: маршрут, тема, viewport/zoom, действие, ожидаемое и фактическое.
```

M-12 согласуется отдельно: нужен явно разрешённый тестовый адрес и настроенный
SMTP. Dev Mailpit подтверждает только локальный transport, а не внешнюю
доставку. Настройка: [docs/mail.md](../mail.md).
