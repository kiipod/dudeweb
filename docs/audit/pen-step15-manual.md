Решение владельца 2026-10-26: единственный незавершённый пункт **M-12 /
N-15-03** перенесён в
[шаг 16 — финальная проверка](../../.agents/plans/pen-integration/16-final-verification.md#m-12--реальная-доставка-reset-письма).
Шаг 15 завершён с этим переносом. M-12 остаётся непроверенным и обязательным
перед production; его исходный ID и критерии ниже сохраняются. Владелец
повторно подтвердил 2026-10-27: SMTP недоступен, M-12 оставить открытым.

Актуальный статус на 2026-10-22: владелец явно подтвердил успешное
выполнение **M-01…M-11**. **M-12: внешний SMTP не проверялся**.
Это результат ручной проверки владельца, отдельно от автоматических
Playwright assertions. Прежняя запись «пока не проверял» superseded.
ОС, браузер, AT и модель устройства в сообщении не указаны; они не выводятся
из browser emulation и не добавляются предположительно.

Использовать обычное окно браузера с приложением, физическую клавиатуру и
собственный тестовый аккаунт. Для screen reader указать сочетание ОС, браузера
и AT: например, Windows + Chrome + NVDA либо macOS + Safari + VoiceOver.
Пароли, reset tokens и персональные ссылки подключения в отчёт не копировать.
