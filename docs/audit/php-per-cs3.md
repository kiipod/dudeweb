# Применение PER-CS 3 к PHP-коду проекта

Дата: 19 октября 2026 года. Базовый commit: `c77396f`.

## Область проверки

Проверены 336 отслеживаемых `.php`-файлов проекта и entrypoint `artisan`:
application code, bootstrap, config, database, routes, tests, опубликованные
переводы MoonShine, formatter config и `public/index.php`.

В `resources/views/app.blade.php` есть Blade directives, но нет PHP-фрагментов.
Этот шаблон просмотрен отдельно и не передаётся обычному PHP CS Fixer.
Шесть `.blade.php`-примеров внутри `.agents/skills/` относятся к содержимому
установленного skill. Они, зависимости, IDE helpers, кеши и SSR output не
входят в исходники приложения и не изменялись.

Выбраны `php-per-cs3` как основной coding-style skill и Laravel skills для
проверки совместимости с проектными соглашениями. Конфигурация разрешённых
Laravel attributes и бизнес-логика сохранены.

## Изменения

- Formatter явно использует `@PER-CS3x0` вместо `@auto`. Автоматические
  PHP migration rules больше не смешиваются с форматированием.
- Дополнительные правила оформляют PHPDoc, удаляют неиспользуемые imports,
  лишние скобки вокруг `new` expressions и однострочные trailing commas.
- Finder охватывает собственные исходники и entrypoints. Опубликованные
  переводы MoonShine включены явно, поскольку стандартный Finder исключает
  каталоги с именем `vendor`.
- Дополнены PHPDoc у всех 1 136 методов: описания, параметры и результаты;
  уточнены явно выбрасываемые и известные передаваемые исключения.
  До изменений у 85 методов отсутствовал PHPDoc, у 876 — описание,
  у 33 — теги части параметров, у 114 методов кроме конструкторов — `@return`.
- Сохранены существующие array shapes и generics, уточнены массивы DTO и
  устаревшие concrete component types в PHPDoc административных страниц.
- Имена 17 cases в четырёх MoonShine enums приведены к PascalCase.
  Их строковые значения, сообщения и цвета сохранены. Новые имена видны
  через `->name`; внутри репозитория внешних обращений к старым именам нет.
- Приведены к стандарту отступы, скобки, imports, переносы аргументов,
  многострочные массивы и цепочки вызовов. Отдельно проверен pipe operator
  PHP 8.5 в `config/yookassa.php`.
- Синхронизированы `AGENTS.md` и документация аудита skills с фактическим
  formatter config.

## Проверка

Все runtime-проверки выполнены внутри Sail: PHP 8.5.6,
PHP CS Fixer 3.95.27.

| Проверка | Результат |
|---|---|
| PHP CS Fixer, весь Finder | 336 файлов, исправлений не требуется |
| `php -l` | 336 PHP-файлов/entrypoints, синтаксических ошибок нет |
| AST-аудит PHPDoc | 1 136 методов; отсутствующих описаний, `@param` и `@return` нет |
| Сравнение AST с базовым commit | 335 исполняемых файлов, неожиданных изменений нет |
| Проверка MoonShine enums | 17 значений, сообщения и цвета совпадают с базовым commit |
| Полный набор PHP-тестов | 163 теста, 1 022 assertions, ошибок нет |
| `git diff --check` | Пройден |

AST-сверка игнорирует комментарии, учитывает разрешённое переименование
enum cases, разрешает эквивалентное разделение trait imports и сравнивает
разрешённые имена классов после обработки namespace imports. Formatter
config исключён из этой сверки, поскольку его поведение изменено намеренно.

В тестах остаются прежние deprecation-предупреждения:
`PDO::MYSQL_ATTR_SSL_CA` в `config/database.php`. PHPUnit обозначает
152 теста как deprecated и 11 как passed; ошибок и failed tests нет.

Команда повторной проверки форматирования:

```bash
./vendor/bin/sail php ./vendor/bin/php-cs-fixer fix \
    --config=.php-cs-fixer.dist.php --dry-run --diff --sequential --using-cache=no
```

Команда тестов:

```bash
./vendor/bin/sail artisan test --compact
```

Локальный текст skill содержит дополнения PER-CS 3.1, тогда как установленный
preset реализует 3.0. Успешный formatter run не означает автоматического
покрытия всех будущих конструкций 3.x. Проверенные дополнительно конструкции
и мягкий предел длины строк требуют review при последующих изменениях;
длинные строковые литералы и SQL не разрезались ради жёсткого ограничения.
